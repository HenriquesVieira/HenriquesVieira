Engenheiro de software full stack em Luanda, Angola.

Construo plataformas multi-tenant de pagamentos, saúde e educação, do desenho da API à operação em produção: pagamentos por referência Multicaixa, facturação electrónica para a AGT e sistemas com os dados de cada cliente isolados dos outros.

## Projectos

**Projectos próprios**

- **[AutoPropina](https://autopropina.ao)**: API de cobranças por referência Multicaixa para escolas e clínicas, com consola de administração. NestJS, Prisma, PostgreSQL, BullMQ, Next.js.
- **Facturação electrónica**: software para a AGT segundo o Decreto Executivo 683/25, com assinatura JWS e SAF-T (AO). Em fase final para a submissão à certificação.

**Para clientes**

- **MediaSync**: sinalética digital sincronizada para Smart TVs, em produção nos servidores de um cliente. Laravel, WebSocket, React, Android TV.
- **Plataforma de gestão escolar**: sistema financeiro, hospedagem e segurança de uma plataforma multi-tenant em produção.

Os repositórios destes projectos são privados. O problema, as decisões e os resultados de cada um estão no [portfólio](https://henriques.autopropina.ao).
