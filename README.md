## 👋 Sobre mim

Sou **Henrique Gomes Vieira**, engenheiro de software **full stack** em **Luanda, Angola**, e actualmente Desenvolvedor Full Stack Sénior na **Saúde+**.

Construo plataformas multi-tenant de pagamentos, saúde e educação, do desenho da API à operação em produção: pagamentos por referência **Multicaixa**, **facturação electrónica para a AGT** e sistemas com os dados de cada cliente isolados dos outros.

- **Facturação electrónica**: software para a AGT segundo o Decreto Executivo 683/25, com assinatura JWS e SAF-T (AO). Em fase final para a submissão à certificação.

- **Plataforma de gestão escolar**: sistema financeiro, hospedagem e segurança de uma plataforma multi-tenant em produção.
